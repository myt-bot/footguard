# 2026-08-14 双人压力动作数据

这组数据来自两位健康体验者的工程测试，仅用于 FootGuard 规则调试和 App 联调，不能作为糖尿病足临床准确率证明。

## 文件

- `person_a_session_01.csv`：第一位体验者。个人基线未锁定，21:16:25 后数据稀疏。
- `person_b_session_01.csv`：第二位体验者。个人基线已完成，是本轮主要调参数据。
- `labels.json`：动作时间、可信度和排除说明。

每行是一只脚的一帧 BLE 数据。`label_confidence=exclude` 的行不能用于阈值统计；`low` 和 `medium` 只用于方向验证。

## 传感器区域

- P1：拇趾区域；
- P2：前掌外侧；
- P3：前掌中央；
- P4：前掌内侧；
- P5：中足中央；
- P6：足跟中央。

当前数据支持将 P1/P4 作为内侧证据、P2 作为外侧主要证据，但正式风险仍必须要求总承重和其他接触点支持，不能由单点残余触发。

## 重新导出

完整数据库不提交到 Git。持有本地数据库的人可在仓库根目录运行：

```powershell
python tools\export_labeled_sessions.py
```
